# Шаблоны документов

## Шаблон User Story (продуктовый)

```
- US-XXX (Priority: P0/P1/P2)
  - Как [роль], я хочу [цель], чтобы [результат].
  - Контекст: ...
  - Что пользователь может сделать: ...
  - Что он видит на выходе: ...
  - Ограничения: ...
  - AC: ...
```

## Шаблон Use Case (системная возможность)

```
- UC-XXX (Capability)
  - Что даёт системе: ...
  - Поведение: ...
  - Признаки успешности: ...
  - Ограничения и риски: ...
```

## Шаблон итерационного traceability

```
| ID      | ID артефакта | Артефакт/решение | AC | Owner | Status |
```

## Шаблон release note (итерация)

```
- Что сделалo
- Что не вошло
- Почему
- Что проверить вручную
- Ограничения/риски
```
