# Open Questions 2026-02-mvp

## Вопросы для решения до финала итерации

- Как пользователь выбирает уровень риска/шумности уведомлений в первых релизах?
- Какой минимальный набор источников включить в первый релиз (без потери MVP ценности)?
- Какой формат хранить в истории нотификаций для удобного просмотра человеком?
- Нужен ли отдельный канал для «важных» уведомлений или достаточно одного с цветовой маркировкой?
- Как формализовать понятие «изменение» для веб-страниц, чтобы снизить ложные срабатывания?

## Решения

- Принять conservative defaults (минимум шумности) и дать пользователю ручную настройку приоритетов на этапе P1.
- Первые источники: тестовый городской новостной поток + один товарный сценарий + один сайт для изменения страницы.
- История отображается в виде карточек с полями `дата/источник/причина/краткое содержание`.
- В MVP один канал уведомлений; цветовая метка для разных уровней важности.
