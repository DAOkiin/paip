# Итерация 2026-02-mvp

## Описание

Первая итерация сосредоточена на контурах, которые дают прямую пользовательскую ценность:

- сбор релевантной информации по задаче,
- выделение новых/изменившихся событий,
- уведомления по каналам,
- история и ручной контроль.

## Ключевой результат

Пользователь может самостоятельно создать рабочий мониторинг, получить релевантные уведомления и в любой момент посмотреть историю по нему.
