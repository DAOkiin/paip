# Итерации разработки

Каталог фиксирует рабочие итерации проекта по текущему порядку:

- `current.md` — указание активной итерации и короткий контур.
- `<iteration-id>/` — набор обязательных и опциональных артефактов для конкретного выпуска.

## Формат итерации

- Идентификатор: `YYYY-MM-<имя>` (например, `2026-02-mvp`).
- Обязательные артефакты:
  - `scope.md`
  - `selected_requirements.md`
  - `architecture.md`
  - `domain_model.md`
  - `event_model.md`
  - `data_model.md`
  - `acceptance.md`
  - `traceability.md`
  - `plan.md`
  - `open_questions.md`
  - `release_notes.md`

## Принцип управления

- Переход между итерациями фиксируется только через обновление `current.md`.
- Исторические данные по закрытым итерациям оставляем в каталоге, но не перезаписываем.
