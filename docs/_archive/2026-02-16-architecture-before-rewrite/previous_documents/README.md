# Документация проекта PAIP

Этот каталог — единый источник истины для проектных решений.

## Быстрый вход

- Продуктовая рамка: `product/global_vision.md`
- Пользовательский контур: `product/global_user_stories.md`, `product/global_use_cases.md`
- Текущая итерация: `iterations/current.md`
- Научный контур: `research/raw_research.md` и материалы в `research/raw/`
- Методика и метаданные: `docs/_meta/doc_system.md`
- Полная структура и назначение каждого файла: `docs/_meta/documentation_structure.md`

## Как работать с документами

1. Изучить `product/global_vision.md` и `product/global_user_stories.md`.
2. Сверить релевантность с `iterations/current.md`.
3. Выбрать итерационные артефакты из `iterations/<name>/`.
4. После изменений обновить трассируемость по `docs/_meta/traceability_policy.md`.
