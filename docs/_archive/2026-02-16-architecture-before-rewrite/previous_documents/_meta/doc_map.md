# Карта документации

## Текущий срез (для работы команды)

- `docs/README.md` — единый вход в документацию.
- `docs/_meta/doc_system.md` — правила структуры и уровней документации.
- `docs/_meta/doc_map.md` — карта рабочих артефактов.
- `docs/_meta/documentation_structure.md` — назначение и содержание каждого файла.
- `product/global_vision.md` — философская цель проекта и долгий контекст.
- `product/global_user_stories.md` — все продуктовые истории пользователя (практические сценарии).
- `product/global_use_cases.md` — возможности системы (scope/модульная карта).
- `product/needs.md` — целевые потребности и метрики ценности.
- `product/personas.md` — целевые роли и их мотивация.
- `product/glossary.md` — единый понятийный слой на уровне продукта.
- `product/nfr.md` — нефункциональные требования (качество, надежность, безопасность, масштабируемость).
- `iterations/current.md` — текущая фокусная итерация.
- `iterations/2026-02-mvp/scope.md` — границы MVP для этой итерации.
- `iterations/2026-02-mvp/selected_requirements.md` — выбранные истории/кейсы с приоритетами.
- `iterations/2026-02-mvp/architecture.md` — архитектурные решения на уровне итерации.
- `iterations/2026-02-mvp/domain_model.md`, `event_model.md`, `data_model.md` — структурные артефакты.
- `iterations/2026-02-mvp/acceptance.md` — что считается готовым по этой итерации.
- `iterations/2026-02-mvp/traceability.md` — матрица требования → решение → проверки.
- `iterations/2026-02-mvp/plan.md`, `open_questions.md` — план и рисковые вопросы.
- `ops/README.md` — индекс эксплуатационных материалов (после запуска MVP).
- `research/raw/` — все сырые материалы.
- `research/raw_research.md` — конспекты и идеи по каждому raw-файлу.

## Архив и исторический контекст

- `docs/_archive/docs_legacy_2026-02-15/` — предыдущие черновики и версии, которые не редактируются.
- Любое решение по продукту/итерации должно ссылаться на актуальные неархивные документы, чтобы не развивать параллельные версии.
