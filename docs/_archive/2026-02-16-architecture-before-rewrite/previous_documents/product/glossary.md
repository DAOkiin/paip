# Глоссарий продукта

- **Мониторинг** — пользовательская инструкция «следи за чем-то и сообщи, если есть существенные изменения».
- **Источник** — внешняя точка данных (лента, сайт, репозиторий, канал), откуда приходит первичная информация.
- **Нотификация** — сообщение пользователю о значимом событии.
- **История нотификаций** — сохранённый список уже отправленных уведомлений с датой и причиной.
- **Городной поток** — выборка событий с фильтрацией по географии для локальных задач (мероприятия/актуальность).
- **Сигнал** — событие, которое прошло порог значимости и попало в уведомления.
- **Новый сигнал** — сигнал, которого не было в ранее сохраненной истории.
- **Изменение** — отличимая разница между текущим состоянием источника и предыдущей версией.
- **Порог** — условие важности, заданное пользователем (например, цена ниже X).
- **Даш-отчёт (дайджест)** — сводка нескольких сигналов одним сообщением.
