# Выбранные требования для 2026-02-mvp

## User Stories (приоритет P0)

| ID | Название | Причина выбора |
|---|---|---|
| US-001 | Уведомления о мероприятиях в конкретном городе с историей | Прямой запрос пользователя, высокая ценность |
| US-002 | Сбор мероприятий в единый поток | Устраняет разрозненность источников |
| US-004 | Уведомления о новых публикациях по теме | Ядро ценности и первое доверие к продукту |
| US-005 | Отслеживание цен и предупреждения | Чёткая ценность и быстрый эффект |
| US-006 | Отслеживание изменений страницы | Практический сценарий с понятным «что изменилось» |
| US-007 | Дайджест уведомлений | Снижение шума и лучшая UX |
| US-008 | Ручной запуск проверок | Срочные ситуации и контроль пользователя |
| US-009 | Добавление/изменение сценариев без разработки | Обязательно для самостоятельного использования |

| ID | Название | Комментарий |
|---|---|---|
| UC-001 | Сбор информации из источников | Базовый движок получения данных |
| UC-002 | Нормализация и единый формат | Нужен для объединенного потока |
| UC-003 | Выявление новизны | Исключение дублей и ложных уведомлений |
| UC-004 | Многоуровневый фильтр и маршрутизация | Приоритеты и минимизация шума |
| UC-005 | Нотификации и история | Непосредственно закрывает пользовательские истории |
| UC-007 | Отслеживание изменений страниц | Реализация US-006 |
| UC-008 | Отслеживание цен и порогов | Реализация US-005 |
