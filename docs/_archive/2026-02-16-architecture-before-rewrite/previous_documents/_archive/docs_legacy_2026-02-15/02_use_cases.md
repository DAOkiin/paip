# 02. Use Cases

Приоритеты: **P0** = MVP, **P1** = следующая итерация, **P2** = потом.

---

## P0 — MVP

### UC-01: Поиск новостей по запросу
- **Роль:** Пользователь
- **Вход:** Поисковый запрос (ключевые слова/тема)
- **Что происходит:** Система через SearXNG ищет свежие результаты, нормализует, дедуплицирует с ранее найденным
- **Выход:** Список новых уникальных результатов
- **Ценность:** Не пропускаю важные новости, не трачу время на повторы

### UC-02: Мониторинг Twitter
- **Роль:** Пользователь
- **Вход:** Twitter-аккаунты или поисковые запросы
- **Что происходит:** Периодический сбор твитов, дедупликация (RT, цитаты), определение новизны
- **Выход:** Новые релевантные твиты
- **Ценность:** Отслеживание инфлюенсеров и тем без ручного скроллинга

### UC-03: Отслеживание цен
- **Роль:** Пользователь
- **Вход:** URL товара + порог цены (опционально)
- **Что происходит:** Периодический парсинг страницы, извлечение цены, сравнение со snapshot
- **Выход:** Алерт при изменении цены (или при падении ниже порога)
- **Ценность:** Покупаю по лучшей цене без ручной проверки

### UC-04: Скрапинг конкретного сайта
- **Роль:** Пользователь
- **Вход:** URL + CSS-селекторы или LLM-промпт для извлечения
- **Что происходит:** Периодический сбор, нормализация, diff с предыдущей версией
- **Выход:** Новые/изменённые элементы
- **Ценность:** Мониторю любой сайт без написания кода

### UC-05: Telegram-дайджест
- **Роль:** Пользователь
- **Вход:** Настроенные мониторы (UC-01..UC-04)
- **Что происходит:** Агрегация результатов за период, форматирование
- **Выход:** Сообщение в Telegram с новыми находками и алертами
- **Ценность:** Единая точка получения информации

### UC-06: Добавление/настройка источника
- **Роль:** Пользователь
- **Вход:** Тип источника + параметры (URL, запрос, частота)
- **Что происходит:** Создание конфигурации, валидация, пробный запуск
- **Выход:** Активный монитор, первые результаты
- **Ценность:** Подключаю новый источник за минуты
